# ХуйняПолнаяOS (hpOS)

> **Хуйня Полнейшая ОС.** Микроядро на Rust, свой BIOS-загрузчик, рабочий стол, браузер
> и говорящий Иззоп. Написано без GNU, без GCC, без эмулятора и без совести.
> На одном-единственном ноутбуке 2006 года.

**by Lowyk and tixcon**

---

## Что это вообще

Самостоятельная настольная ОС. Не дистрибутив Linux с обоями, а своё ядро,
свои процессы, свой IPC, свой загрузчик, своя файловая система, свой шрифт.
Linux тут гость, который не пришёл.

Целевое железо: **Toshiba Satellite P100-222** (Core 2 Duo T5600, 2006 год,
чипсет ICH7, PS/2-клавиатура и тачпад, видеокарта, которая, мягко говоря,
не в лучшей форме). Если ОС запускается на нём, на вашем ноутбуке она
тем более подумает о запуске.

## Список достижений

- 🥾 **Свой загрузчик.** MBR → stage2 → ядро, Legacy BIOS, INT 13h, E820, VBE.
  GRUB не приглашали: он GNU, а у нас с этим строго.
- 🧠 **Микроядро.** Ядро знает про память, планирование и прерывания. Всё остальное
  (ввод, рисование, файлы, сеть) живёт в ring 3 в отдельных адресных пространствах
  и общается через IPC с правами по handle.
- 🖥️ **Рабочий стол.** Окна, перетаскивание, анимации, светлая и тёмная тема,
  четыре акцента, сглаженная кириллица. Всё рисует CPU, потому что GPU
  на целевом ноутбуке работает исключительно как кусок текстолита с фреймбуфером.
- 📁 **Файловая система HPFS.** Своя. Окно «Файлы», редактор, терминал с командами.
- 🌐 **Интернет через телефон.** USB-драйверы EHCI и UHCI, RNDIS, а поверх них
  Ethernet, ARP, IPv4, ICMP, UDP, DHCP, DNS, TCP и HTTP/1.1. Всё написано с нуля,
  внешних зависимостей нет. Телефон подключён по кабелю, ноутбук 2006 года
  открывает сайты. Да, это работает как рэп под аккомпанемент модема.
- 🔎 **Браузер.** Текстом, без картинок, без JavaScript, зато с кодировками
  (UTF-8, cp1251, KOI8-R) и поиском. HTTPS пока открывается через читалку FrogFind,
  потому что TLS ещё не написан. Это честно и написано ниже.
- 🤬 **Иззоп.** Локальная «нейросеть» в терминале (`izzop`). Без Python, без GPU,
  без облака: статистическая модель около 180 КБ, которая отвечает репликами
  как люди, на чьей переписке её учили. Что-то среднее между оракулом и пьяным другом.
- 🦀 **20 тысяч строк Rust**, из них внешних зависимостей: **ноль**.

## Чего здесь принципиально нет

| Нет | Почему |
|---|---|
| GNU, GCC, GPL, LGPL, AGPL | Принципиально. Даже в инструментах сборки. |
| QEMU и любых эмуляторов | Они тоже под GPL. Поэтому всё тестируется на железе. |
| Внешних Cargo-зависимостей | Чужой код это чужие баги. Свои багов не имеют, только фичи. |
| Linux под капотом | Какой уж тут Linux. |

«Тестируется на железе» значит буквально: образ едет на флешку, флешка в ноутбук,
ноутбук в кадре, пользователь присылает фото экрана. Отладчик здесь называется
«фото журнала на экране». Так нашли, например, 64-битный баг в очередях EHCI
(Host System Error, код `1005b014`) и приключение, когда Huawei выдаёт себя за флешку.

**Горячие клавиши:** F1 система, F2 помощь, F3 настройки, F4 файлы,
F7 браузер, F8 сеть, Tab переключает окна.

## Как запустить

Нужны Python 3.9+, Rust (edition 2024) с target `x86_64-unknown-none` и Clang
со встроенным ассемблером для x86. LLD берётся из Rust toolchain.

```text
rustup target add x86_64-unknown-none
python3 tools/build.py
```

Получится `build/hpos.img`, сырой образ диска на 32 МиБ. Дальше:

1. Положить образ на флешку с **Ventoy** и загрузить через **Memdisk**.
   Для сети это обязательно: образ лежит в памяти, и BIOS не нужен USB.
2. Нужен ПК с Legacy BIOS (не UEFI), поддержкой INT 13h и VBE-режимом
   от 800×600 с линейным 32-битным фреймбуфером.
3. Для интернета: телефон по USB, на нём включить режим USB-модема (RNDIS),
   в hpOS открыть «Сеть» (F8) и нажать «Подключить».

Образ пишется только в файл. Скрипт сборки на физические диски ничего не пишет.

## Проверки

```text
cargo test --offline -p hpos-boot-protocol -p hpos-memory -p hpos-x86-paging \
  -p hpos-scheduler -p hpos-ipc -p hpos-service-protocol -p hpos-desktop \
  -p hpos-fs -p hpos-izzop -p hpos-net
python3 -m unittest discover -s tests -v
cargo fmt --all -- --check
```

Тесты проверяют логику (протоколы, память, планировщик, IPC, сетевой стек против
поддельного «телефона», браузер и раскладку). Они **не** заменяют запуск на
железе: драйверы USB, прерывания и ring 3 проверяются только им.

## Про Иззопа

Сам Иззоп (код, формат модели, тренер) лежит в [crates/izzop](crates/izzop).
А вот **обучающий корпус в репозиторий не входит**: это личная переписка авторов,
и она останется личной. Хотите своего Иззопа: положите по одному сообщению
в строке в `private/izzop/corpus.txt` (или укажите файл в `HPOS_IZZOP_CORPUS`)
и пересоберите образ. Без корпуса команда `izzop` честно скажет, что Иззоп спит.

## Устройство репозитория

```text
boot/        MBR, stage2, переход в защищённый и длинный режим, вызовы BIOS
kernel/      микроядро: память, планировщик, прерывания, PCI, системные вызовы
services/    службы ring 3: ввод, дисплей и рабочий стол, файлы, сеть (EHCI/UHCI/RNDIS)
crates/      библиотеки: память, страницы, IPC, планировщик, HPFS, рабочий стол,
             сетевой стек, Иззоп, протоколы между службами
docs/        архитектура, журнал проверок на железе, описания версий
tools/       сборка образа
tests/       проверки структуры образа
```

Старый подробный README с историей версий: [docs/history-and-checks.md](docs/history-and-checks.md).
Архитектура: [docs/architecture.md](docs/architecture.md).
