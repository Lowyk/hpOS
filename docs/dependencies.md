# Политика компонентов и сборки

В hpOS и её цепочке сборки запрещены GNU-компоненты и зависимости под
GPL, LGPL и AGPL, включая зависимости, транзитивно попадающие в сборку.
Для каждой добавляемой зависимости проверяются её конкретная версия,
лицензия, транзитивный состав и содержимое поставляемого бинарного файла.

На этапе 0.8 нет внешних Cargo-пакетов и стороннего кода загрузчика.
Файловая система HPFS, переходник BIOS и служба ФС написаны в проекте.
Службы ввода и рабочего стола собираются из собственного Rust-кода;
их ELF-образы упаковываются стандартной библиотекой Python.
Растровые символы диагностического экрана нарисованы в проекте.

Рабочий стол 0.6 использует производный bitmap atlas **hpOS Interface** из
Noto Sans, лицензия **SIL Open Font License 1.1**. Лицензия и copyright сохранены
в `crates/desktop/assets/font-OFL.txt`; исходный commit, SHA-256 шрифта и атласа —
в `font-source.json` рядом. Источник: [официальный Google Fonts, закреплённый commit](https://github.com/google/fonts/tree/8b0a1d0f5983c89bc2b93f1b5fb55f9e252744b5/ofl/notosans).
Это единственный новый сторонний ресурс; OFL относится к этому шрифту/атласу,
не задаёт лицензию собственному коду ОС.

С версии 0.8 из того же шрифта сделаны ещё два атласа: 20 px полужирный
(`title.bin`, 59019 байт) и 34 px жирный (`display.bin`, 175911 байт).
Параметры и SHA-256 всех атласов — в `font-source.json`.
Атлас интерфейса из 191 символа ASCII/кириллицы хранит 4-битное сглаживание и занимает
33807 байт. Он включён в исходники: обычная офлайн-сборка не скачивает шрифт
и не запускает генератор. Для регенерации на macOS используется собственный
`tools/font-atlas.c`, Apple Clang и CoreText/CoreGraphics/CoreFoundation.
В ОС нет зависимости от этих macOS frameworks.

| Инструмент | Назначение | Основная лицензия upstream |
|---|---|---|
| Rust / Cargo | Rust-код и организация сборки | MIT или Apache-2.0 |
| Clang integrated assembler | собственный x86-ассемблер | Apache-2.0 с LLVM exceptions |
| LLD из Rust toolchain | линковка ELF | Apache-2.0 с LLVM exceptions |
| Python standard library | упаковка ELF и дискового образа | PSF |

Это перечень выбранных инструментов, не полный аудит бинарных дистрибутивов.
Rust поставляет `COPYRIGHT.html` с информацией о сторонних компонентах своего
релиза и `COPYRIGHT-library.html` с информацией о библиотеках. Конкретные
установленные сборки инструментов требуют проверки этих сведений перед
фиксацией официального окружения и распространением сборочного комплекта.

LLD использует название интерфейса `gnu` для линковки ELF и понимает совместимый
синтаксис linker scripts. Это режим LLVM LLD, а не запуск GNU linker.
GCC, GNU assembler, GNU linker, GNU objcopy и GNU Make в сборке не вызываются.
Python вызывает инструменты напрямую, без shell-команд и внешнего objcopy.

Источники:

- [Rust COPYRIGHT](https://github.com/rust-lang/rust/blob/main/COPYRIGHT).
- [LLVM licensing](https://llvm.org/docs/DeveloperPolicy.html#licensing).
- [Python license](https://docs.python.org/3/license.html).

Собственная лицензия hpOS будет выбрана авторами отдельно. До этого проект
не объявляет MIT, BSD или другую лицензию от их имени.
