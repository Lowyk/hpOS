# Сеть: что дальше

Первая версия — USB-модем RNDIS, IPv4 и браузер по HTTP — сделана в 0.10,
подробности в [network-0.10.md](network-0.10.md). Дальше по важности:

1. **Проверка на железе** с Huawei P60 Pro и исправления по журналу окна «Сеть».
2. **CDC ECM и NCM.** Некоторые телефоны отдают модем не через RNDIS. ECM
   простой (кадры как есть в bulk-передачах), NCM упаковывает несколько кадров
   в блок NTB.
3. **HTTPS.** Почти весь веб работает через TLS. Нужны SHA-256, HMAC, AES-GCM
   или ChaCha20-Poly1305, X25519, проверка сертификатов (RSA/ECDSA) и корневые
   сертификаты. Пока HTTPS-страницы открываются через читалку FrogFind, то есть
   без шифрования до неё.
4. **Формы** (поиск на сайтах), **картинки** (хотя бы GIF/PNG) и сохранение
   страниц в «Файлы».
5. **USB-мыши и клавиатуры** через UHCI (сам драйвер UHCI для модема уже есть).
6. Продление аренды DHCP, несколько TCP-соединений, IPv6.

Бюджет ядра больше не мешает: загрузчику доступно 2,9 МБ, ядро со службами
занимает около 1 МБ.
